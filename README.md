## 📌 Sobre o Projeto

Este repositório reúne as soluções da lista de exercícios focada em **Estruturas de Dados e Listas** em Python. 

O objetivo principal deste conjunto de atividades é aplicar na prática os métodos de manipulação de coleções dinâmicas, desenvolvendo algoritmos capazes de receber, armazenar, ordenar e filtrar volumes de dados informados pelo usuário de forma estruturada.

### 🧠 Conceitos e Operações Aplicadas:
- **Métodos de Inserção e Remoção:** Uso prático de `.append()`, `.insert()`, `.pop()` e `.remove()` para gerenciar o ciclo de vida dos elementos na lista.
- **Pesquisa e Varredura:** Algoritmos de busca linear para encontrar índices ou verificar a existência de itens com o operador `in`.
- **Estatística Computacional Básica:** Varredura de listas para extração de somatórios, cálculos de médias aritméticas, além de identificação de valores máximos e mínimos (`max()` e `min()`).
- **Compreensão de Listas (`List Comprehensions`):** Aplicação de sintaxe concisa e performática do Python para transformar e filtrar coleções de dados.

## 📐 O Diferencial das Listas em Python

Em Ciência da Computação, estruturas de dados lineares costumam exigir o gerenciamento manual de ponteiros ou tamanhos fixos. As listas do Python abstraem essa complexidade, funcionando como arrays dinâmicos de alta performance. Os exercícios deste repositório ajudam a entender como utilizar essa facilidade de forma inteligente e limpa, preparando a base para estruturas mais complexas.
